# Instagram Clone - SwiftUI

An Instagram-like social media application built using SwiftUI and Firebase.

## Features

- User authentication (Sign up, Login, Logout)

- Profile management (Edit profile, change profile picture)

- Post creation

- Like and comment functionality

- Real-time notifications

- Explore feed with trending posts

- Secure database and cloud storage integration using Firebase

## Tech Stack

- SwiftUI - Modern UI framework

- Firebase - Authentication, Firestore Database, Storage

- Combine - Reactive programming

- MVVM Architecture - Clean separation of concerns using the Model-View-ViewModel pattern

## Architecture
- The project follows the MVVM (Model-View-ViewModel) architecture:
- Model: Represents the data and business logic (e.g., User, Post models)
- View: The SwiftUI views that present UI elements to the user
- ViewModel: Handles data processing and interacts with Firebase, updating the Views accordingly
- This structure ensures a scalable, maintainable, and testable codebase.
